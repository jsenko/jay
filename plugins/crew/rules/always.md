# Always

Every session reads this, so it competes with the task for the whole
session. Hence the length.

## Dates

Long sessions drift. Run `date +"%A %Y-%m-%d"` at startup and before
anything time-sensitive; never trust a system reminder's date.

## Capacity

More than the user can take? Bring the most important few, not all of
it. A list nobody can act on is the same as no list. When unsure which
few, ask — a question costs less than undoing the wrong choice.

## Friction

When a rule or command is confusing, contradictory or missing, capture a
note tagged `meta` saying what would fix it.
